ES6 কী? (সহজ ভাষায়) 😊

ES6 মানে হলো ECMAScript 6।
এটা JavaScript-এর একটি নতুন ও আধুনিক ভার্সন, যা ২০১৫ সালে প্রকাশ করা হয়।
ES6 আসার পর JavaScript লেখা সহজ, ছোট ও পরিষ্কার হয়েছে।

সহজ করে বললে

👉 ES6 হলো JavaScript-কে আরও powerful বানানোর জন্য যোগ করা কিছু নতুন ফিচারের সেট।

ES6 আসার আগে সমস্যা কী ছিল?

কোড অনেক বড় হতো

একই কাজ বারবার লিখতে হতো

ভ্যারিয়েবল কন্ট্রোল করা কঠিন ছিল

👉 ES6 এই সমস্যাগুলো সহজ করেছে।

ES6 এর গুরুত্বপূর্ণ ফিচার (Beginner Friendly)

1️⃣ let ও const
আগে শুধু var ছিল, এখন:

let → মান বদলানো যায়

const → মান বদলানো যায় না

2️⃣ Arrow Function (=>)
ফাংশন ছোট করে লেখা যায়

3️⃣ Template Literal ( )
String এর ভিতরে সহজে ভ্যারিয়েবল বসানো যায়

4️⃣ Default Parameter
ফাংশনে ডিফল্ট মান দেওয়া যায়

5️⃣ Destructuring
Array বা Object থেকে সহজে ভ্যালু বের করা যায়

6️⃣ Spread Operator (...)
Array/Object কপি বা মর্জ করা সহজ

7️⃣ Class
JavaScript-এ OOP স্টাইল আনে

8️⃣ Import / Export
ফাইল ভাগ করে কাজ করা যায়

কেন ES6 শিখবে?

✅ কোড ছোট হয়
✅ পড়তে সহজ
✅ Modern JavaScript এর বেসিক
✅ React, Vue, Node.js শেখার জন্য দরকার
